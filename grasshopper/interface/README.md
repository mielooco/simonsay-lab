# Grasshopper 學習筆記・第一單元：認識介面

首頁獨立分組 `#grasshopper-basics` 的第一個單元，正式入口 `grasshopper/interface/index.html`。

五頁：開啟與視窗、介面地圖與選單、分類與找工具、畫布操作、參數／單元／連線。最後一頁以四個觀察重點共用同一份可操作流程。

術語：Parameters 稱「參數」；Components 稱「運算元件」，簡稱「單元」。

`index.html` 內嵌程式、樣式及三張圖片，可直接開啟本機檔案；介面截圖可縮放、平移及點選位置。連線流程是簡化教學示意，並非 Grasshopper 執行環境。學習筆記與瀏覽進度僅儲存在目前瀏覽器；不同瀏覽器或網址不會自動同步。

修改 `source.html`、`style.css`、`app.js` 後執行 `python3 build.py`。圖片及技術參照來源見 `assets/sources.json`，並於頁面保留署名連結。
