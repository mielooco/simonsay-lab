LEVEL 4：幾何精確 Fillet — 弧線掃描建構
尺寸控制 · Dimensions
圓角控制 · R-Angles
精度控制 · Mesh
教學觀察重點：
1. 高度連動：R_top + R_bot 之和不能超過總高 H，縮小 H 時兩者自動等比縮減。
2. 垂直 R 角上限：R_vert 受寬度與深度的最小值限制，感受角落圓度與整體比例的關係。
3. 不對稱頂底：頂部設大 R、底部設小 R，觀察量體「重心」的視覺偏移。
4. Segments：調低至 8 感受低模稜角感，調高至 48 感受工業曲面的細膩。

1. 高度連動：R_top + R_bot 之和不能超過總高 H，縮小 H 時自動等比縮減。
2. 垂直 R 角：受寬深最小值限制，感受角落圓度與比例的關係。
3. 不對稱頂底：頂部大 R + 底部小 R，觀察量體「重心」的視覺偏移。
4. Segments：8 = 低模稜角感，48 = 工業曲面細膩。
