# Simon Fundamental Design Lab
### 造型基本設計實驗室

> 設計人，尋找造型的老靈魂

**🔗 課程入口 → [https://mielooco.github.io/SimonSay-lab/](https://mielooco.github.io/simonsay-lab/)**

---

## 關於這個課程

給正在學習造型設計的互動造型課程。  
每個 Level 都是一個可以動手玩的 3D 實驗室，從 R 角開始，理解形體的語言。

不需要安裝任何軟體，打開瀏覽器就能玩。  
支援手機與桌機，自動切換 UI 佈局。

## 課程設計邏輯

```
L01 塊體感知        → 從零開始，最單純的R角與量體
L02 布林交集        → 不同方向R角碰撞的硬邊界
L03 比例與方向性     → 不同比例容器裡 R角在的視覺重量
L04 幾何精確        → 從近似升級為 CAD 真實邏輯
L05 複合路徑        → 建模順序如何決定造型氣質
L06 斜角截面        → Chamfer 的面積消長與交界協商
L07 截面與輪廓      → 固定底部，依序觀察頂部與中段截面的影響；高度可獨立調整
L08 挖與切          → 比較球面挖凹與平面切削，再從不同角落疊加最多三刀
L09 量體整合        → 回顧 L01–L08，整合比例、垂直與水平圓角、截面切線與橫向握槽
L10 點、線、面      → 由點連成線、線圍成面，再觀察前中後曲線共同構成曲面
L11 曲線的建立      → 比較幾何條件與點位控制、固定 R 與沿線曲率，為後續曲面建立與編輯準備
L12 環帶曲面        → 從半輪廓、截面建立兩段環帶，檢查鏡射與上下接面
L13 定位與造型      → 以滑鼠為例，編輯 XYZ 定位點，觀察輪廓與局部曲面的連動
```

## 使用方式

直接點上方的課程連結，用滑鼠（或手指）拖拉旋轉 3D 物件，拉動滑桿即時觀察造型變化。

- **桌機**：左側浮動控制面板
- **手機 / 平板**：底部抽屜 UI，自動偵測觸控裝置切換

---

Level 07 先顯示三步課前簡圖，點「開始實驗」進入操作，也可隨時「重看說明」。中段鼓收以直線為基準，回到 0 或切回收分可還原直線；「重置」恢復直筒、頂部 100%、中段鼓收 0、高度 130 與初始視角。

中段操作另有「不限制端部切線」開關：預設保留原收分的端部切線（頂底同尺寸時為垂直），開啟後端部方向可隨鼓收改變；兩種模式在鼓收為 0 時均還原直線，重置會關閉此開關。

第 3 步的 3D 視圖預設顯示切線虛線（第 1、2 步自動隱藏）：白色標示縱向輪廓，橘色標示上下端與中段的切線方向。標示隨模型參數與旋轉視角更新，可使用視圖右上方按鈕隱藏。

第 09 課先顯示五步課前簡圖，再進入插頭外殼工作台。各步設定會保留，亦可回看簡圖；中間截面可上下移動，主輪廓切線可保持垂直或自由調整，上下兩段在中間截面共用切線。端部圓角另行疊加；橫向凹槽可作用於寬面、窄面或兩面，並調整深度與槽寬。兩支插腳固定為銀金屬色。操作設定保存在目前瀏覽器，重置可恢復預設造型與視角。

L01–L05 進入課程前先顯示課前簡圖，點「開始實驗」進入原有操作；桌機與手機都可用「課前簡圖」回看說明，並保留當前參數與視角。L02 著重不同圓角交會的交線，L03 著重比例與 R 的視覺佔比，L04 比較頂、底與垂直 R 的配置，L05 依序呈現前端 R1、後端 R2 與側面相切鏈 R3。

L06 先以截面圖認識 D1（水平縮進）與 D2（下切深度），再分別固定其中一項，比較頂面縮小與下方垂直側面變矮。桌機與手機皆可「重看說明」，保留參數與視角；原有斜角幾何、尺寸控制及即時角度顯示維持不變。

L10 先以動畫建立點、線與面的關係，再依序操作「拉動 F」「前後曲線」「連成曲面」。直接上下拖動粉色點調整起伏、沿水平方向拖動 A／B／C／D 調整寬窄，拖曳空白處旋轉視角。可重看動畫，並保留造型與視角設定；設定儲存在目前瀏覽器。

### Level 11 曲線的建立

先看七步課前簡圖，再操作圓與圓弧、橢圓、通過點與控制點、S 形曲率比較。S 形圓弧移動 J 時固定 A、B，保留共同切線；自由曲線提供四個沿弧長取樣位置、即時曲率大小與曲率梳。兩圖梳線使用同一線性倍率；四個值是取樣，不是四段固定曲率。

可縮放視圖、直接拖點與重新點選自由曲線。圓半徑 1–30 mm；自由點位 ±30 mm；圓弧端點 ±40 mm。所有實驗設定儲存在目前瀏覽器，重看課前說明或課程整理後可繼續操作；重新開啟課程仍先顯示導讀。課末說明曲線條件如何影響曲面建立、銜接、修改與加厚。

### Level 12 環帶曲面

六步導讀先演示三條半輪廓、截面、上下兩段曲面、鏡射及接縫比較，再分階段操作截面弧度、鏡射端點切線、兩段接面切線。截面共五條：A、E 是前後對稱面上的截面，B 位於 A–C 中點、D 位於 C–E 中點。上、下段弧度以兩條獨立滑桿同時顯示，不需切換面；截面圖也可直接拖動各段控制點；A、E 在對稱面內調整前後弧度，左右保持接合，輪廓端點保持固定；C 的橘色中輪廓可上下調整 Z，帶動上下兩段共同變形，並能直接上下拖動 C 接點。可復原、重置、重看說明，瀏覽器保留實驗與視角。3D 旋轉與縮放分開。

曲線參照原始滑鼠資料；截面與曲面為教學重建，不等同原始 CAD 鋪面。

### Level 13 定位與造型

先看四步課前簡圖，再依序調整半寬 X、腰線高度 Z 與前後位置 Y。可直接拖點、復原上一步、回到原始造型，重看說明與重新整理會保留操作設定。3D 旋轉使用固定中心與比例，縮放由獨立按鈕控制（50–150%）；「重設視角」恢復預設角度與 100%，保留造型。桌面並排、手機垂直，各視圖維持等比例；局部參考線只標示兩條輪廓之間的控制影響範圍。

本課為原始滑鼠幾何的教學變形，不等同 CAD 歷程重算；參考線不能取代曲率、接面與厚度檢查。
